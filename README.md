1. Совместимость с PHP 8.3 и 8.4
- Удалённые функции (create_function(), strftime() и другие).
- Устаревшие конструкции и предупреждения PHP.
- Ошибки типов, аргументов функций и обработки массивов.
- Совместимость с MODX Revolution 3.2.4.

2. Работу всех функций модуля
- Создание и сохранение заявок.
- Добавление участников и представляющих лиц.
- Загрузку, хранение и удаление изображений.
- Отправку уведомлений и писем участникам.
- Фильтрацию, поиск и сортировку заявок.
- Административные операции.
- JavaScript и AJAX-обработчики.

3. Возможности самого модуля
- дополнительные фильтры заявок;
- экспорт и группировка заявок;
- управление статусами;
- массовые операции;
- дополнительные уведомления;
- другие возможности административной части.
